# 📌 Sobre o Projeto

O **PortfolioHUB** foi desenvolvido com o objetivo de organizar projetos acadêmicos e pessoais utilizando boas práticas de versionamento com Git e hospedagem no GitHub.

O projeto também foi criado para fortalecer o portfólio profissional e aplicar conceitos de:

- Versionamento de código
- Organização de repositórios
- Documentação de projetos
- Publicação web com GitHub Pages
- Integração profissional com LinkedIn
